# Scripts

database migration and portal-user seeding) that go beyond the root
`Makefile` wrappers, per
[Implementation Design §17.1](../docs/design/05-implementation-design.md#171-folder-ownership).

secret-scan commands are defined in the root [`Makefile`](../Makefile).
