# Prompts

Reserved for a small number of sanitized, reusable AI-assistance prompts
that teach a repeatable method, per
[AI-Assisted Engineering Plan §18](../docs/ai/10-ai-assisted-engineering-plan.md#18-engineering-journal-strategy).

Prompts kept here are reviewed like source: no secrets, credentials, or
sensitive/real business data. Raw prompt history and chain-of-thought are
excluded; see `engineering-journal/` for per-work-unit evidence instead.

No prompts have been retained yet.
