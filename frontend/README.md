# Frontend

React + TypeScript (strict) + Vite, linted with ESLint, formatted with
Prettier, and tested with Vitest and React Testing Library. See the root
[`README.md`](../README.md) and
[Implementation Design §6](../docs/design/05-implementation-design.md#6-frontend-design)
for scope and boundaries.

Run from the repository root via `make lint-frontend`, `make typecheck-frontend`,
`make build-frontend`, `make test-frontend`, or `make frontend-dev`; or
`cd frontend && npm run <script>` directly.
